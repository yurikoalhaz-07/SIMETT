Parameter Meteorologi

Variabel fisik atmosfer yang diukur untuk memahami cuaca.

Apa Itu Parameter Meteorologi?

Parameter meteorologi adalah variabel fisik atmosfer yang diukur untuk memahami kondisi cuaca dan memprediksi keadaan atmosfer di masa depan. Parameter ini diamati menggunakan berbagai instrumen seperti termometer, barometer, anemometer, hygrometer, dan sensor radiasi.

Klasifikasi Parameter Meteorologi
  • Parameter Prognostik — variabel yang digunakan dalam persamaan pengatur atmosfer untuk memprediksi kondisi.
  • Parameter Diagnostik — diturunkan dari parameter prognostik, atau diamati sebagai akibat proses atmosfer.
  • Parameter Hidrometeorologi (High Impact) — untuk memahami dan memprediksi kondisi hidrometeorologis.
  • Parameter lain (penerbangan/pelayaran) — kondisi saat ini, visibilitas, jumlah petir, dsb.
Parameter Prognostik

Temperatur

°C / °F / K

Ukuran energi kinetik rata-rata molekul udara (panas/dingin).

Instrumen: Termometer.

Kelembapan

% RH
g/kg

Kadar uap air: absolut, spesifik, mixing ratio, dan kelembapan relatif.

Instrumen: Higrometer / psikrometer.

Tekanan Udara

hPa / mb

Gaya kolom udara; sinyal sistem tinggi/rendah.

Instrumen: Barometer.

Angin (Laju & Arah)

m/s
knot

Kecepatan horizontal dan arah asal angin (derajat dari utara).

Instrumen: Anemometer.

Komponen Vektor (u, v)

u (zonal): + barat→timur, − timur→barat. v (meridional): + selatan→utara, − utara→selatan.

Radiasi

W/m²

Pancaran energi EM (cahaya tampak, UV, IR) untuk neraca panas permukaan.

Instrumen: Pyranometer, pyrgeometer, pyrheliometer, netradiometer.
Parameter Diagnostik

Presipitasi

mm/jam

Hujan/salju/es yang jatuh; intensitas penting untuk banjir.

Instrumen: Rain gauge.

Tutupan Awan

okta
%

Fraksi langit tertutup awan.

Instrumen: ceilometer / observasi.

Konsentrasi Gas

ppm / µg/m³

Jumlah gas di udara (mis. CO₂, H₂O).

Instrumen: Gas analyzer.
Parameter Hidrometeorologi

Evapotranspirasi

Gabungan evaporasi + transpirasi.

Satuan: mm/hari. Instrumen: Evaporimeter/panci.

Tinggi Muka Air

Pemantauan muka air untuk hidrologi dan banjir.

Instrumen: pengukur muka air.
